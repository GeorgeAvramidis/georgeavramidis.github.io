# George Avramidis Portfolio

A personal Data Analyst portfolio built with HTML, CSS and vanilla JavaScript. It is designed for GitHub Pages and has no build step, framework or package manager.

## Preview

Open index.html in a browser. All site pages, styles, scripts, project images and the CV use relative paths.

## Customize the site

- Edit the introduction, services, education, certifications, skills and contact links in index.html.
- Update the four project summaries in index.html and their detailed case studies in case-studies/.
- Replace the project visuals in assets/projects/ when a project changes. Keep the current filenames or update the matching image paths in the HTML.
- Replace assets/George_Avramidis_CV.pdf with the public CV PDF you want visitors to download.
- Adjust colors, typography, spacing and responsive layouts in styles.css.
- Theme preference, the mobile menu, project filters and reveal effects are handled in script.js.

The displayed project findings are based on the project documentation available when this site was prepared. Confirm the figures and date ranges before publishing future updates.

## Publish with GitHub Pages

This repository is named GeorgeAvramidis.github.io, so it can publish as a user site at https://georgeavramidis.github.io/.

1. Keep index.html at the repository root.
2. Push the site files to the main branch.
3. In the repository, open **Settings**, then **Pages**.
4. For branch publishing, choose **Deploy from a branch**, select main and the / (root) folder, then save.
5. Open the site URL after the Pages deployment finishes.

The site is static. GitHub Pages can host the HTML, CSS, JavaScript, images and PDF directly, with no separate build command or paid service.
